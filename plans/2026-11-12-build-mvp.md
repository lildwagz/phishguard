## Komponen & kriteria selesai
1. **Model** `src/model/train.py` → `model/phishguard.joblib` + `model/metrics.json`
   - TF-IDF (kata 1–2 gram + karakter 3–5 gram) + Logistic Regression `class_weight=balanced`; bandingkan dengan MultinomialNB.
   - verify: akurasi ≥85% (NFR-03) **dan** F1 phishing dilaporkan, juga per bahasa (en/id).
2. **API** `api/` (FastAPI): `GET /health`, `POST /v1/predict {text}` → `{label, confidence, model_version, latency_ms}`
   - FR-02: teks kosong/spasi → 422 dengan pesan jelas; batas panjang 2.000 karakter.
   - NFR-02: isi pesan tidak disimpan/di-log (log hanya panjang + label + latency).
   - CORS terbuka untuk Flutter web.
   - verify: pytest (health, predict phishing/aman, input kosong, tidak ada teks di log) + uji latency p95 ≤ 3 detik (NFR-01).
3. **Docker** `api/Dockerfile` + `docker-compose.yml` → verify: `docker compose up` lalu curl `/health` & `/v1/predict`.
4. **Flutter** `mobile/`: layar input → tombol Analisis → kartu hasil (label + confidence), validasi kosong, riwayat lokal (FR-03, shared_preferences), URL API bisa diatur.
   - verify: `flutter analyze` bersih, `flutter test` lulus, `flutter build web` sukses, uji manual web → API berjalan.
5. **Docs**: README status/cara menjalankan, plan ini diisi hasil.

- **Docker**: `docker compose up -d --build` → api :8000 (healthcheck) + web (nginx) :8080. CORS preflight dari :8080 OK.
- **Flutter**: SDK 3.47.9 resmi di `~/development/flutter` (sha256 dicek). `flutter analyze` 0 issue, 4/4 widget test, `flutter build web` OK. Uji e2e di Chrome headless (CDP): validasi kosong ✓, pesan phishing → kartu PHISHING 96,9% + masuk riwayat ✓.
